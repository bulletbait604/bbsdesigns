# How to use the Cursor prompts

1. Open the project repository in Cursor.
2. Give Cursor prompt 001.
3. Let it inspect and build.
4. Run the tests it requests.
5. Do not skip failed tests.
6. Give prompt 002 only after prompt 001 is stable.
7. Continue numerically.
8. Commit to Git after each successful phase.
9. Keep AUTO_PUBLISH=false.
10. Do not put API keys into source code.

If Cursor tries to implement a risky shortcut, stop it and restate the relevant safety requirement.
