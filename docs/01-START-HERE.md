# 01 — Start Here

## Goal
Build the first version of the AI Merch Factory without spending heavily on new services.

## Existing services to use
- Cursor Pro
- Vercel Pro
- MongoDB
- Any AI APIs you already pay for
- Cloudflare R2 if already available

## Add only what is necessary
- Shopify store
- Shopify Partner/development access
- Printify account
- One image-generation API

## First store
Niche 1: Gaming humor
Niche 2: Baseball humor
Niche 3: Softball humor

Tone:
- funny
- sarcastic
- cheeky
- mildly risqué
- adult humor without explicit sexual content

Never generate:
- copyrighted characters
- game logos/assets
- professional sports logos/marks
- celebrity likenesses
- copied slogans
- hateful content
- slurs
- threats
- graphic violence
- explicit sexual content

## Development mode
Use:
HUMAN_APPROVAL=true
AUTO_PUBLISH=false

Only consider automatic publishing after testing.
