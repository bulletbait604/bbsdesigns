# 04 — Safety Rules

Every product receives one of:
PASS
REVIEW
REJECT

## Hard reject
- recognizable copyrighted characters
- copyrighted game artwork
- logos
- trademarks used as branding
- professional sports team marks or mascots
- celebrity likenesses
- copied slogans
- instructions to imitate a specific protected brand/artist
- hateful content
- slurs
- threats
- targeted harassment
- graphic violence
- explicit sexual content

## Important
A trend score can never override a safety rejection.

If the model is uncertain, use REVIEW.

Every decision must be logged with:
- input
- rules triggered
- provider
- model
- model response
- risk score
- decision
- policy version
- timestamp
